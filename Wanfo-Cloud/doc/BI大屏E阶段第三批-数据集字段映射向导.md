# E 阶段第三批：数据集字段映射向导

日期：2026-10-18。状态：看板/大屏模板创建支持三步向导、批量统一数据集与跨数据集字段名重映射；S12-T04 仍部分完成（不含已发布看板上的批量替换）。

## 使用方式

看板管理 → 新建数据大屏 → 选择内置或导入模板 → 每个数据组件可切换：

- **从已保存图表**：沿用 E1/E2 行为，选择图表并确认字段。
- **从数据集映射**：直接选择当前有权 `query` 的数据集，系统按槽位类型给出推荐维度/度量映射，可打开「配置字段映射」调整聚合、排序与附加筛选；影响检查会提示缺失字段、指标卡/饼图形状错误等问题。

验证当前绑定或创建草稿前，数据集直绑会为该组件**创建或更新一张专用已保存图表**（名称形如「{大屏名} · {槽位名}」），大屏仍通过 `chartId + chartConfig` 取数，不改变后端发布/权限模型。创建前仍会整板 `preview` 校验。

## 边界

- 创建向导内可「应用到全部数据槽」并「验证全部绑定」；切换数据集时按字段名（含大小写）尽量保留映射。
- 不替代已保存看板草稿上的全量批量替换；不做 DataEase 模板文件兼容。
- 数据集直绑生成的图表会留在图表库中，便于审计与复用，不会自动删除。
- 字段影响分析基于当前用户可见的数据集字段清单，不能代替服务端 `preview` 与行列策略校验。
- 宿主适配 H-01 未因本批完成；无新增 Flyway 或后端接口。
