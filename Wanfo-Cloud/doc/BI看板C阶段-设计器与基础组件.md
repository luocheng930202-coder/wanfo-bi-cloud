# C 阶段首批：独立设计器与基础组件

## 页面与交互

资源列表 `/bi-admin/dashboard` 保留资源管理、授权与发布消费；新建/编辑进入 `/bi-designer/:id?`。独立设计器包含顶部文档操作、组件/图层区、栅格画布、选中属性区；窄屏使用工具抽屉。图表源从当前用户有 query 资格的已保存图表中选择，服务器仍重新验证权限。

已实现选择、复制、删除、标题/对齐/内容/几何属性、文档撤销/重做、保存、发布和离开保护。命令历史最多 50 状态，280ms 输入合并；分支编辑舍弃重做分支；保存更新基线且不清空历史。文本或布局撤销不会清空未变化的数据组件结果；绑定变化或恢复已删除数据组件会重新取数。删除组件同步清理该组件相关目标/来源，并可整文档撤销恢复。

Ctrl/Cmd+Z 撤销、Shift+Z / Y 重做、D 复制、Delete/Backspace 删除；输入框与对话框保留原生键盘行为。发布必须使用服务器返回的最新文档版本，仍受 CAS、功能权限及资源发布资格限制。

## 协议

保留 schemaVersion=1，Panel 新增可选 content，componentType 扩展 chart / kpi / text / image。旧缺省类型仍为 chart。

- chart：chartId 必填，冻结已保存图表。
- kpi：chartId 必填，取源图表第一个聚合度量，去掉分类维度及排序后执行同一固定筛选下的总聚合。第一个度量为 NONE 时拒绝保存；不将分类首行当作总指标。发布时冻结转换后的 QueryModel。消费结果维度为空、度量一个，实际数值继续使用显示格式，不改变精度。
- text：chartId 必须为空，content.text 为纯文本、最多 2000 字符；以 Vue 插值输出，不渲染 HTML。
- image：chartId 必须为空，content.image 为 PNG/JPEG/WebP 的 data URL，校验 MIME、Base64、文件头及 256KB 大小。不接受远程地址和 SVG。图片随定义保存；这是首批小素材方案，后续素材服务与模板生命周期另行实现。

静态空内容可暂存草稿，发布前要求文本/图片完整。总定义与发布快照最多 1M 字符。静态组件不导出图表、不生成 chart/dataset 绑定，也不提供取数接口；消费清单直接携带已发布静态内容。KPI 继续建立实际图表/数据集引用保护，与 chart 采用相同使用者消费资格及行列规则。

过滤器可绑定 chart/kpi 的实际字段；静态组件不能成为数据目标。KPI 不能作为点击来源，图表第一维度可联动 KPI。查看清单不包含图表 ID、数据集 ID、源查询和绑定字段。服务端身份/资源接口不变，未将若依主体类型写入文档。
