# 零售指挥大屏 — 演练验收清单

配套数据脚本：`ruoyi-modules/ruoyi-bi/deploy/demo-retail-screen.sql`  
加载命令：`deploy/seed-retail-screen.ps1`（写入 `bi_phase_a_test`，与本地数据源 id=58 对齐）

搭建步骤见 [零售指挥大屏-搭建手册.md](./零售指挥大屏-搭建手册.md)。

## 阶段 A — 数据与权限

| # | 项 | 通过 |
|---|----|------|
| A1 | 数据源试连、浏览 `dim_store` / `fact_order` 等表 | ☐ |
| A2 | 表数据集：`ds_store`、`ds_product`、`ds_order`、`ds_target`、`ds_ops_note` | ☐ |
| A3 | 关联建模宽表 `ds_retail_wide`（order→store、order→product） | ☐ |
| A4 | 计算字段 `unit_price = amount/qty`（或等价） | ☐ |
| A5 | （可选）行规则：测试账号仅 `city=杭州市` | ☐ |
| A6 | （可选）列隐藏/脱敏一列 | ☐ |

## 阶段 B — 图表库

| # | 项 | 通过 |
|---|----|------|
| B1 | 柱图（区域，配置下钻 `province→city→store_name`） | ☐ |
| B2 | 折线（按 `order_date` 趋势） | ☐ |
| B3 | 饼/环/漏斗（渠道或品类） | ☐ |
| B4 | 地图（维 `province`，度 `SUM(amount)`） | ☐ |
| B5 | 透视（行 `category`，列 `province`） | ☐ |
| B6 | 明细表、仪表盘(gauge) 或 KPI 用表 | ☐ |
| B7 | 图表样式/高级 Tab 保存重开一致 | ☐ |

## 阶段 C — 数据大屏

| # | 项 | 通过 |
|---|----|------|
| C1 | 模板市场「运营监测大屏」+ 向导绑定 `ds_retail_wide` | ☐ |
| C2 | 槽位：metric-a/b KPI，analysis-a 柱图+下钻，analysis-b 明细 | ☐ |
| C3 | 增补：地图、漏斗、透视、折线、文本标题、图片(素材) | ☐ |
| C4 | 容器/组合/装饰线；场景 30s 刷新 | ☐ |
| C5 | 筛选：城市(text)、渠道(enum)、金额(number)、日期(date) | ☐ |
| C6 | 联动：非下钻柱图 → 明细（下钻图不作联动来源） | ☐ |
| C7 | 草稿预览 → 发布 → 消费/全屏 | ☐ |
| C8 | 存私有模板并再实例化一版 | ☐ |

## 链路完整性（必达）

| # | 标准 | 通过 |
|---|------|------|
| L1 | 改 `fact_order` 一行后，发布消费端能看到变化 | ☐ |
| L2 | 钻取路径与面包屑/API `drills` 一致 | ☐ |
| L3 | 改草稿不影响已发布 revision | ☐ |
| L4 | 无权限组件单独失败，不拖垮整屏 | ☐ |
