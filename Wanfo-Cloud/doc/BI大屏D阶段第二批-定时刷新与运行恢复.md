# D 阶段第二批：定时刷新与运行恢复

日期：2026-10-17；状态：基础闭环完成，D 阶段整体仍部分完成。

## 协议与操作

scene.refreshSeconds 为可选整数，缺省/0关闭，启用范围10～3600秒。前后端同时校验；旧三参数 Scene 和旧 JSON 可继续读取，归一化默认关闭。沿用原 dashboard 资源、若依功能码、BI 资源与数据权限，不新增宿主依赖和数据库迁移。保存草稿不改变已发布间隔；发布清单冻结设置。

设计器“大屏”属性提供自动刷新秒数，仅交互预览和发布查看运行，编辑画布不启动定时查询。显示周期、暂停及最近尝试时间；最近尝试不代表所有图表均成功，失败继续由页面/组件错误提示表达。

## 调度边界

单个递归定时器在上一轮完成后再计时，不补跑错过的周期。遇到正在执行的刷新、组件查询或候选值查询时等待，不叠加自动请求。发布端组件取数仍最多两个工作线程。页面隐藏或路由失活暂停后续自动调度，恢复后安排一次刷新；若已有刷新在执行，则等其结束后再进入下一周期。卸载时销毁定时器和 visibilitychange 监听。

页面隐藏不会取消已经发出的服务端查询；发布端自动刷新轮次在继续取下一个组件前再次检查可见性。已有响应的代次检查保留，过期响应不覆盖当前页面。普通栅格看板和关闭自动刷新的既有手动加载行为保持。

同一发布版本保留待应用输入、已应用筛选与联动；自动刷新只使用已应用条件。每轮先获取当前发布清单，发现新版本则按新配置恢复默认条件，避免旧字段绑定串入新版本。网络/权限/下线等失败清空失效数据并提示，下一周期重试；原权限检查仍由后端逐次执行。刷新时保留上一轮图表直至新结果或失败返回，减少空白闪烁。
