| 验证项 | 结果 | 耗时 |

**核心结论：Spring Boot 4.1.0 与 Calcite 1.42.0 完全兼容。**

classpath 上 Jackson 2.21.4（Calcite 内部用）与 Jackson 3.1.4（Spring Boot Web 层用）共存无冲突，**无需降级 Spring Boot，也无需隔离到独立进程**。

### 1.4 前端构建验证

~~~text
npm install        -> 540 packages / 2 min
npm run build:prod -> BUILD SUCCESS / 48 s
npm run dev        -> VITE v6.4.1 ready in 3485 ms / HTTP 200
~~~

**Node 24 + Vite 6 + TypeScript 5.6.3 组合通过。**

⚠️ **npm 11 陷阱**（团队内必须记录）：npm 11 默认不执行第三方包安装脚本，必须先执行：

~~~bash

npm rebuild esbuild @parcel/watcher vue-demi
~~~

## 附录 A：Calcite 1.42.0 API 陷阱速查

> 全部为本项目实测踩坑。网上旧教程（基于 Calcite 1.2x/1.3x）会全部踩中。

### A.1 六个必须知道的 API 变化

| # | 陷阱 | 现象 | 正确写法 |
|---|---|---|---|
| 1 | `JdbcSchemaFactory` **已移除** | `ClassNotFoundException` | `JdbcSchema.create(root, name, ds, null, null)` |
| 2 | **model.json 配置方式失效** | `JsonJdbcSchema` 是包内类，无法作为 `SchemaFactory` 插件被反射实例化 | 只能用代码式注册 |
| 3 | `create()` **不自动挂载** | schema 明明注册了却报 `Object not found` | 必须显式 `root.add(name, schema)` |
| 4 | **默认大小写敏感且转大写** | `Object 'POCA' not found` | 连接属性 `lex=MYSQL_ANSI` + `caseSensitive=false` |
| 5 | `commons-dbcp2` 是 runtime scope | 编译期找不到 `BasicDataSource` | pom 显式声明 |
| 6 | `JdbcSchema.dataSource()` 参数顺序不符预期 | `Cannot load JDBC driver class 'root'` | 自己 `new BasicDataSource()` 显式 set |

### A.2 可直接复用的正确实现

~~~java
// 1) 建立连接（必须设置 lex 与 caseSensitive 对齐 MySQL 行为）
Properties props = new Properties();
props.setProperty("lex", "MYSQL_ANSI");
props.setProperty("caseSensitive", "false");
Connection conn = DriverManager.getConnection("jdbc:calcite:", props);

// 2) 动态注册 schema（BI 的数据源是运行时配置的，只能代码式）
CalciteConnection calciteConn = conn.unwrap(CalciteConnection.class);
SchemaPlus root = calciteConn.getRootSchema();

BasicDataSource ds = new BasicDataSource();
ds.setDriverClassName("com.mysql.cj.jdbc.Driver");
ds.setUrl("jdbc:mysql://host:port/db");
ds.setUsername("u");
ds.setPassword("p");
JdbcSchema schema = JdbcSchema.create(root, "myschema", ds, null, null);
root.add("myschema", schema);          // 必须 add，否则查不到

// 3) 执行查询
try (Statement st = conn.createStatement();
     ResultSet rs = st.executeQuery("SELECT ... FROM myschema.mytable")) {
    ...
}
~~~

### 关键技术决策记录

| # | 决策 | 理由 |

| 8 | 权限表拆两张 | 行级（SQL 注入）与列级（结果裁剪）执行时机与失败后果不同 |
