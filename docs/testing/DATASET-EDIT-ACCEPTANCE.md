## 权限和保守限制

- 定义编辑要求数据集资源 edit 权限及数据源建模权限；查询、消费和填报写入不自动获得编辑权限。SQL节点继续要求管理员。
- 图表按字段名称/编号识别引用；看板草稿/发布绑定、质量、指标、权限、填报、流程和数仓范围依赖，对删除及类型变化先采取保守阻断，未宣称全部完成字段级精确分析。
- 不显示无权查看的引用资源名称。
- 带结构迁移字段映射的数据集应通过迁移流程维护；数仓绑定变更也保留原有治理入口。
- 保存事务失败会回滚；本批没有新增可供用户选择的历史版本回滚。
- 本批未增加将已保存SQL数据集拖为关联右节点的能力，该功能缺口仍保留。
