# BI 四项权限与填报修复说明

日期：2026-10-19。对应《BI项目复核与后续开发优化计划》的 P0-01～P0-04。

## 1. 计算字段权限传播

计算表达式使用 Calcite AST 解析，只允许白名单标量运算/函数及当前数据集字段。裸字段和 `[field]` 均识别为依赖，字符串常量不作为依赖；拒绝子查询、语句、未知函数和跨限定名称。DENY/MASK 向依赖它的计算字段传播为 DENY，避免还原物理字段原值。策略解析为查询、看板消费、分享、导出、字段选择器共用。

含计算字段的单表预览改用表达式展开；源库标识符引用使用 JDBC 方言，Calcite 查询仍使用双引号，避免 MySQL 将计算字段名当作字符串常量。关联预览保留完整字段类型用于规则校验，输出时再剔除禁止字段。

非法历史表达式将拒绝查询，需要管理员修正；没有放宽为任意 SQL。当前保存层仍只允许物理字段参与计算；权限传播支持多级依赖，但本次没有开放多级计算字段编辑。

## 2. 导出执行与下载重新授权

新增宿主中立的 `LiveActorResolver` 契约。若依适配器从当前用户、角色、部门和菜单权限读取可信身份，拒绝已禁用/删除用户及未知来源，不继续使用任务创建时的角色/资格。

提交、执行、下载均重新解析身份。下载重新执行服务端保存的源查询，检查图表/看板/数据集资格与当前行列规则，并核对结果及用户/角色/部门摘要。原结果或身份发生变化时拒绝返回旧文件，要求重新导出。下载增加一次有行数上限的查询成本；这是当前保守失效策略，后续可引入策略版本与权限凭证减少重复查询。

历史文件没有验证摘要，升级后需要重新导出。下载不会信任客户端查询、字段列表或摘要。源权限撤销、源不可用时均不会继续返回旧内容。

## 3. 发布者范围分享

`publisherActorJson` 仅保留主体引用；创建和访问发布者范围分享时重新解析当前身份，并要求当前 publish/consume 功能资格和看板 publish 资源资格。组件查询继续检查当前数据集 consume 与行列规则，角色移除、部门变化和用户停用不再沿用旧快照。

viewer 范围保持访问者身份与数据范围。嵌套执行后恢复原调用上下文，失败时也清理上下文。分享仍要求登录。本次没有扩展匿名嵌入，也没有将分享密码慢哈希、分布式尝试限制和访问审计列为已完成；这些是原计划的后续分享加固项。

## 4. 填报写入和审计

- 新增 dataset `write` 资源动作，界面显示“填报写入”。全局 `bi:form:submit` 与 dataset view/query 不再隐含源库写入资格；资源所有者/BI 管理员仍按已有机制授权。表单管理也要求 write。
- 仅写入绑定单表的物理字段；不接受关联模型作为写入目标。提交值校验当前固定行条件及列限制，DENY/MASK 字段拒绝写入。提交与记录查询使用实时身份。
- 提交要求 `X-BI-Submission-Id`，格式为 16～80 位字母、数字、下划线或短横线。前端为一次填写生成 UUID；同一内容网络重试复用该标识。唯一键范围为表单＋内部主体＋提交标识；同标识改内容返回 409。
- V17 迁移扩展 `bi_data_form_record`，增加所有者、请求标识、内容摘要与状态。先通过独立 `REQUIRES_NEW` 事务持久化 pending 意图，再执行源库事务；失败/成功审计也使用独立事务。预留失败则不执行源库 INSERT。
- 确认成功为 succeeded；提交前失败回滚并保留 failed；提交确认丢失记 uncertain；审计更新失败保留 pending。相同标识无论 pending/failed/uncertain/succeeded 都不再次写库。语句超时为 30 秒。
- 普通用户只查询自己的记录，并按当前行条件过滤、隐藏禁止列、脱敏受限列。管理员可查询表单记录。历史无所有者记录仅管理员可见，不猜测或自动绑定历史创建人。

跨库没有使用 XA，不能声称分布式原子提交或 exactly-once。pending/uncertain 需要按记录 ID 和业务唯一键人工核对源库，不能换新标识盲目重发；本次没有自动补偿重写和人工核对管理页。支持跨源写入前仍需对目标数据库的事务能力另行验收；现场验证范围为 MySQL/InnoDB。

## 部署与适配

先备份元数据并执行 V17，再部署新后端和前端。现有角色菜单资格沿用若依；需要填报的非所有者新增 dataset write 授权。历史导出请重新提交，历史填报记录由管理员查阅。

当前 `bi.security.mode=ruoyi` 提供实时身份适配器。未来独立部署应实现相同 `LiveActorResolver`、CurrentActorProvider、CapabilityProvider 与主体目录契约；核心导出、分享、填报服务不直接读取 sys_* 表。本次没有新增独立账号系统。

## 新发现的后续任务

现有新增计算字段将 originType 写为 `CALC`；SUM/AVG 数值检查因此返回 400。本次权限验证使用 MAX 及原生预览验证派生值，未绕过类型检查。后续应推断表达式真实返回类型并迁移旧 CALC 元数据，覆盖数值/字符串/空值计算及聚合，不应将所有 CALC 字段粗暴视作数值。该功能问题与本次依赖权限传播修复分别记录。
