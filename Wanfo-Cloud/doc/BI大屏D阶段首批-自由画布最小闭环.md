# D 阶段首批：自由画布大屏最小闭环

2026-10-17。接续 C7/C8 与 BI 类型检查第一批进入 D。当前完成自由坐标编辑与保存发布消费，不将全部大屏能力或模板功能计作完成。

## 协议与兼容

保留 schemaVersion=1，新增显式载体 kind=screen/layout=absolute 与 scene={width,height,fit}。设计宽度 320～8192、高度 240～8192；fit 为 contain/width/none，分别等比适配、宽度适配、原始尺寸。scene 必须存在；dashboard/grid 不接受自由画布尺寸，载体与布局不能混搭。

screen 的 x/y/w/h 为整数像素，组件至少 20×20，不能越出设计尺寸；允许重叠，panels 数组从下到上定义图层。dashboard/grid 原 12 列、120 行、尺寸 2～12 及不重叠规则保持。组件数量、内容、格式、字段映射、查询权限、文档大小与并发版本限制继续共用。大屏不是把栅格画布全屏显示。

定义和发布快照各自保存 scene 与数组顺序，发布清单返回冻结载体、设计尺寸及布局；消费端不按 y/x 重排自由图层。不读取旧表中预留宽高字段作为本期权威定义，不改写已执行迁移，无新增数据库迁移。旧客户端不支持 screen 时应拒绝编辑，避免降级成 grid。

## 编辑与查看

看板管理新增「新建数据大屏」，默认空白 1920×1080；选择组件后使用像素属性、拖标题移动、右下角缩放、上下移一层。指针位移按编辑缩放比例换算为设计像素，边界夹取，抬起后一次提交文档历史；pointercancel/失焦/卸载回收状态，组件锁定限制编辑。复用多选、原子对齐/移动/分布、复制删除和撤销重做，栅格默认参数兼容。

大屏属性可设尺寸与适配方式，编辑缩放 25%～200% 不写入文档。修改尺寸后有越界组件会拒绝保存，需要修正布局；不静默重排或丢弃组件。自由组件默认尺寸为像素，新增/复制采用偏移放置，允许有意重叠。图表字段配置及单卡刷新携带正确 screen 协议，仍走作者预览。

查看端只读，不提供拖动/缩放手柄；按发布尺寸和适配渲染，复用现有筛选、候选值与联动、格式及素材副本。当前大屏与看板共用 dashboard 资源和 bi:dashboard:* 功能资格，仍通过若依适配及 BI 资源/数据策略，不另建身份或使用作者身份代查。
