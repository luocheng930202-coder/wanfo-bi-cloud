## 验证方法

发布验证以 Git 索引导出的全新目录为来源，不复用原工程 target、dist 或 node_modules。重新安装前端依赖、运行脚本测试、BI 类型检查和生产构建；重新执行后端 Maven verify。运行验证使用独立 Docker 项目、空 MySQL/Redis 和独立端口，不操作已有业务数据库。

本地 Gitleaks 固定 8.30.1，官方发行文件校验 SHA256。报告输出始终使用 `--redact=100`，不把密钥明文写到扫描报告或 CI 日志。CI 同样校验扫描器发行文件并扫描新仓库历史。
