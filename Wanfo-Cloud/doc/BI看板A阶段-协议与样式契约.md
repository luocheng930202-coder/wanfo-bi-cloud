## 定义与兼容

继续使用 `schemaVersion: 1`，向现有文档增加可选字段：`kind: dashboard`、`layout: grid`、`appearance`；组件增加 `componentType: chart`、`style`。省略新增字段的旧 JSON 可读取，服务在返回时补齐默认值，读取不回写数据库。既有 key、chartId 和 12 列栅格位置保持原义，无需数据库迁移。

当前拒绝未知版本、screen 载体、free 布局及其他组件类型。预留的载体与布局边界不代表大屏已经实现；以后扩展应通过明确的协议迁移和验证器实现，不能将自由坐标直接送入栅格验证逻辑。

```json
{
  "schemaVersion": 1,
  "kind": "dashboard",
  "layout": "grid",
  "name": "经营概览",
  "appearance": {
    "theme": "dark",
    "background": "#111827",
    "cardBackground": "#1F2937",
    "textColor": "#F3F4F6",
    "borderColor": "#4B5563",
    "palette": "business",
    "titleSize": 14,
    "radius": 6,
    "decimals": 2,
    "grouping": true
  },
  "panels": [{
    "key": "sales", "componentType": "chart", "chartId": 4,
    "title": "销售额", "x": 0, "y": 0, "w": 6, "h": 8,
    "style": { "showTitle": true, "titleAlign": "left" }
  }]
}
```

样式默认浅色、商务配色、14px 标题、6px 圆角、最多 2 位小数及千分位。每个颜色只接受 `#RRGGBB`，不接受任意 CSS、URL 或脚本。主题仅 light/dark，配色仅 business/ocean/warm；标题字号 12～24，圆角 0～24，小数位 0～6；标题对齐 left/center/right。

数字格式仅用于数值显示、坐标轴和提示，不修改查询模型及原始结果。字符串保持字符串，避免将编码、精确数值字符串或日期变成浮点数。小数位为最大显示位数，不强制补零。隐藏标题的编辑组件保留拖拽入口，消费态保留无障碍名称。

## 保存、发布与权限

保存草稿继续使用现有版本号 CAS，校验每个引用图表的当前资格和布局。发布复制已保存的载体、布局、主题、卡片属性及查询配置；消费清单从发布快照读取样式，不从最新草稿读取，也不返回查询模型、数据集 ID 或图表 ID。

当前身份、角色、组织和功能权限继续由若依适配器提供；新协议和样式验证器不依赖若依会话或用户表。消费取数仍采用当前使用者的数据集消费资格及行列规则，样式不携带权限或作者身份。未来独立模式通过既有主体、能力和资源授权接口适配。
