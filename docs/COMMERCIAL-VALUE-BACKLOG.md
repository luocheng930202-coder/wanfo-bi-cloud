**建议先定一条对外主卖点**，再从对应 P0 包取项：

## 4. 明确不纳入本清单主线

与产品宪章 §2.1 / S3「不对齐」一致，**不得**因「提升商业价值」默认升 P0：

- DataWorks / WeData 全量对标、湖仓一体、PB 级实时、自建 CDC 内核  
- 开放生产 SQL/脚本写仓、多租户 SaaS 计费、第二套权限体系  
- 连接器数量竞赛、全民 BI 应用商店  

此类须单独业务触发 + ADR，并改宪章或路线图后再立项。
