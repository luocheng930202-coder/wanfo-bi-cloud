# C 阶段第五批：图片素材库首批

日期：2026-10-17。用户新增的大屏模板选择需求已记录在 WBS 的 S12-T02/T04/T05：大屏创建提供空白创建/从模板创建，经分类搜索与预览进入独立草稿，显式完成数据集/字段映射后保存发布。该需求随 D/E 衔接交付，本批继续 C 素材服务。

## 已实现

图片组件属性新增「从素材库选择」，支持素材命名上传、按权限分页浏览、选中预览、使用及删除。库内上传仅支持 PNG/JPEG，文件不超过 256KB；服务端复核编码、魔数并实际解码，尺寸不超过 4096×4096 且总像素不超过 1600 万，拒绝 SVG、远程 URL、损坏和伪造图片。原本的直接上传 PNG/JPEG/WebP 入口保留，不扩展原协议。

列表每页 20 项，不返回图片数据；只有获权详情请求返回图片。服务端先过滤当前主体可见资源再分页。首批存储实现为元数据库 bi_image_asset，AssetStorage 接口与 DatabaseAssetStorage 实现分离，可替换为文件/对象存储；不是已经接好 MinIO/若依文件服务。

每项素材通过现有 BI 内部主体与 bi_resource 记录真实所有者，功能权限为 bi:asset:list/add/remove，资源检查为 asset.view/remove。当前提供所有者/管理员使用和删除，尚未提供跨主体素材授权界面。不信任前端按钮可见性，普通用户知道其他素材 ID 仍不能读取/删除。核心依赖宿主无关的 CurrentActorProvider、CapabilityProvider、BiResourceAuthorizer，若依响应包装仅扩展适配层。

## 选入与生命周期

「使用此素材」将内容复制到选中图片组件，复用现有大小/文档上限、撤销重做和保存发布流程；取消选择不修改文档。素材选入与发布不依赖公开静态 URL，查看者只通过其有权看板获得冻结图片副本。删除库中素材清空库内图片并逻辑删除记录，已保存草稿/已发布快照保留其图片副本，不会形成悬空引用。故本批采用复制语义，不声称引用式素材保护已实现。

显式上传即创建持久素材；取消选择不会回滚已主动上传的库中资源。尚无模板暂存上传，因此模板临时归属/过期回收属于 E 阶段待办；不将普通持久素材自动过期删除。

组件锁定、加载或保存时不能使用素材；异步操作中关闭/重复打开选择器受限，失败提示并保留可重试入口。

## 迁移与部署

新增 V9__bi_image_assets.sql，保留 V1～V8 原样。本地升级前已备份 ry_vue 到 .local/bi-integration/bi-before-v9.sql，V9 增量迁移通过。deploy/ruoyi-menu.sql 增加 3 个按钮功能码并保持幂等；已安装到本地，普通角色不自动获权，测试角色仅用于隔离验收后回收。

接口：GET /bi/asset?page=1，GET /bi/asset/{id}，POST /bi/asset（name/image），DELETE /bi/asset/{id}。均需有效登录及对应功能权限，详情和删除还需资源资格。没有匿名素材下载路径。
