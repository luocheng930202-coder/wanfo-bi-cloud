# C 阶段第六批：组件级指标格式

日期：2026-10-17。本批提供组件级度量显示格式，复用当前身份、查询、文档历史和发布机制，不改变查询语义。独立度量级覆盖、阈值和指标比较仍为后续事项。

## 功能与协议

数据组件属性新增「数值格式」开关。关闭时沿用旧全局外观；开启后可配置数值/百分比、小数位 0～6、固定补零、千分位、不缩放/千/万/百万、前后缀及空值文本。百分比按原值乘 100，不能同时单位缩放；百分比数据本身若已为 0～100，需要业务方先明确指标语义，不能自动猜测。

Panel.style 新增可选 numberFormat：`{mode,scale,decimals,grouping,fixed,prefix,suffix,nullText}`。后端对枚举、数值和文本校验，文本最多 20 字符且不得含控制字符；不接收任意 CSS/脚本执行配置。旧 PanelStyle 两参数构造和 JSON 读取兼容，缺省 numberFormat=null。无需数据库迁移。

格式作用于 KPI 值、图表度量明细、数值轴和 Tooltip；维度不使用组件度量格式。图形原始数据、维度联动值、排序、聚合和筛选不变，百分比或单位缩放仅在显示时执行。前后缀为文本，模板插值及 richText 提示不作为 HTML 执行。

格式在编辑时响应显示，参与现有文档撤销重做、保存、草稿预览与发布快照。发布后修改草稿不会改动发布版；格式配置本身不触发额外查询。

## 数值精度

格式化使用十进制字符串与 BigInt 做缩放和四舍五入，负数以绝对值半入后恢复符号，不通过 Number 转换高精度数字字符串。支持有界科学计数法，固定补零可关闭，负数舍入为零时不显示负零。非数值字符串保持原文本；null 使用 nullText，0 为真实数字。

输入本身已经是 JavaScript number 且早已失去的精度不能恢复；图形仍保留既有安全绘图范围限制，超大值查看明细。无组件覆盖时维持旧全局显示行为，包括旧表格空值不强制新增占位符。未来导出接入时需明确原始值与格式值策略，本批未实现导出。
