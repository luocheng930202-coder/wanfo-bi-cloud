# 二维食堂驾驶舱与刷新策略验收

本文是本地验收步骤，页面实际操作尚未执行。自动化检查通过不替代真实数据、权限及发布验收。

## 前置条件

- 当前用户可查询测试数据集、创建图表与看板；发布验收另需发布权限。
- 采购、费用、用餐和验收数据分别明确事实粒度，学校/地区编码采用相同编码体系。
- 统一日期筛选使用 DATE 字段。原始时间戳先转换为业务时区的日期；不得直接按服务器默认时区截断。
- 验收合格率使用每条有效验收记录上的数值 0/1 标识，学校数使用学校编码去重计数。
- 准备正常结果、无匹配结果、空值与真实零值等数据范围；不在生产数据上做异常演练。

## 结果记录

每次实际验收记录：时间、测试身份及权限范围、数据集名称、默认筛选、草稿/发布版本、预期值计算方式、实际结果和必要截图。不要记录密码、Token 或业务敏感明细。

当前自动化覆盖包括：模板严格解析与实例化、字段类型与聚合规则、统一筛选映射和默认值、空值/零值与查询错误、模拟时钟下刷新退避和调度清理。尚不能据此证明真实数据库业务口径、跨用户隔离或长时间运行已通过。

## 真实 3D 行政区地图操作入口

1. 在图表管理中创建或打开行政区地图，设置地区值为“行政区编码”，维度使用对应层级的地区编码，度量按业务口径聚合；需要省市县下钻时，分别配置各级地区字段。先在二维地图确认查询结果。
2. 在大屏编辑器插入“3D 场景”，在“样式 → 场景类型”选择“行政区地图（3D）”（原名称“区域分布”），点击“设置地图数据”，再点击“绑定行政区地图图表”选择上一步的地图。场景继承图表的地图范围与地区编码配置。
3. 进入草稿预览或发布查看，单击匹配地区查看选择状态；有可用下级时双击或从“地区指标”列表点击“查看下级”。用组件上方的面包屑返回上级。
4. 若已配置看板地区联动，可以从列表点击“筛选此地区”。查询和路径权限仍由原看板接口校验。
5. 当前只有行政区边界与地区度量，不含学校经纬度点位或建筑实景模型；经纬度平面展示不用于测绘。
