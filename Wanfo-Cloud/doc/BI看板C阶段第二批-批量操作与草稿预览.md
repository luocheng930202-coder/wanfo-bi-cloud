# C 第二批：批量编辑与草稿交互预览

## 编辑操作

Panel 新增可选 locked，v1 旧文档默认 false，读取不回写。锁定是编辑器防误触状态，非资源权限；有编辑权的调用方可通过正常保存修改锁定。查看清单不需要展示锁定状态。

Ctrl/Shift 点击或多选模式增减选择，Ctrl/Cmd+A 全选，Esc 清除选择；输入控件和对话框内不拦截原生快捷键。第一个选中组件为对齐基准；六种对齐保持组件尺寸，中心位置按整数栅格 Math.round 取整。整个结果须处于 12 列/120 行范围内且不重叠，否则返回原文档。存在锁定项时禁止对齐、复制和删除，先统一解锁。多选时禁止单卡拖动/缩放，单选后可操作；群组拖动和等距分布不在本批内。

锁定同时配置 GridStack locked/noMove/noResize，防止拖动、缩放和被其他节点推挤。批量对齐、复制、删除、锁定各构成一个历史命令；复制位置全部找到后才写入，空间或容量不足则整批不执行。复制不自动扩展筛选/联动映射。删除相关数据组件需确认，并清理失去目标的筛选器、来源或目标联动；撤销恢复整个文档。选择状态、运行筛选状态不写入文档历史。

## 草稿预览接口

新文档：POST `/bi/dashboard/preview` 和 `/bi/dashboard/preview/options/{key}`，要求 bi:dashboard:add。

已有文档：POST `/bi/dashboard/{id}/preview` 和 `/bi/dashboard/{id}/preview/options/{key}`，要求 bi:dashboard:edit、资源 view+edit 和当前草稿版本。

请求为 `{version, definition, input}`。definition 是可含未保存修改的 v1 文档；input 仅允许 `{filters,links}`，语义和 B 阶段一致。客户端不得指定查询结构；服务端从有权限的已保存图表导出真实查询，并校验目标字段/类型。每次预览都重新检查作者权限和图表/字段绑定，已有文档版本不匹配返回 409。

预览使用当前编辑者的 chart/dataset query 授权和行列规则，不要求 dataset consume，也不使用发布者身份。只有 consume 授权不足以预览，query 撤销立即拒绝；正式查看接口继续独立执行消费者 consume 授权。候选值同样走编辑者查询策略、去掉自身控件条件、至多 100 项。

预览返回 `{view,payloads}`，manifest revision=0，仅为预览清单，不是已发布版本。结果去除 executedSql/params，不写草稿、发布快照、版本或绑定引用。静态组件无需取数。锁定不限制数据取数，也不改变行列规则。

客户端进入预览固定当前草稿副本，默认值立刻生效；修改输入只有应用后生效，清空/恢复默认只更新输入。点击图表直接叠加活动联动，应用筛选清除旧联动。退出后保留原文档与历史，运行条件不落库。预览和候选值请求使用代次/序号防旧响应；一次预览请求在服务端顺序执行数据组件，不声明服务器已取消过期执行。单个组件失败会使本轮预览失败，界面清除旧结果并提示修正/重试，不把旧结果当作新条件成功。

## 验证

121 项 BI 测试、15 项布局断言、10 项历史断言、13 项显示兼容断言，以及 22 项 MySQL 接口检查通过；前端生产构建通过。工程既有全量 vue-tsc 类型声明阻塞仍存在。
