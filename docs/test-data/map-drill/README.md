# 省市县地图下钻测试数据

全部为确定性生成的模拟销售数据，不代表真实业务。地区名称、编码与项目内置 2021.5 边界快照一致，不代表最新行政区划。

- 时间：2026 年 1—3 月；每个区县每月一条记录。
- 规模：372 条、6 个省级地区、8 个普通地级市、124 个区县。北京、上海直接进入区县层级。
- 省级范围：上海市、北京市、四川省、广东省、江苏省、浙江省。
- 普通城市：南京市、宁波市、广州市、成都市、杭州市、深圳市、绵阳市、苏州市。
- 模拟销售额合计：222461.58；模拟订单数为独立整数指标。
- CSV：`province-city-county-sales.csv`，UTF-8 BOM，可用 Excel 打开。包含省/市/县编码与名称、月份、销售额、订单数。

## 本地系统入口

- 数据源：地图下钻测试数据源（模拟），ID 109。
- 数据集：省市县销售测试数据（模拟），ID 168，位于“地图下钻测试（模拟数据）”目录。
- 推荐：编码匹配地图 http://localhost/bi-admin/chart-workspace/134/view
- 对照：名称匹配地图 http://localhost/bi-admin/chart-workspace/135/view

在地图点击有颜色的省份，或在明细表点击“下钻”。例如全国 → 浙江省 → 杭州市 → 各区县；点击路径中的“浙江省”或“全国”返回。直辖市示例为全国 → 北京市 → 各区县。区县为最终层级，不继续进入乡镇。未覆盖地区不生成虚假数据。
