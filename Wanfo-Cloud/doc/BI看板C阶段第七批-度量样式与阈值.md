# C 阶段第七批：度量独立格式与阈值颜色

2026-10-17。Panel.style.metrics 新增可选数组，每项为 `{key,format?,rules}`：key 是有效查询输出度量别名；format 复用 C6 有界格式，缺省时沿用组件格式，再沿用全局外观。单组件最多 20 个度量样式，度量键唯一，允许中文别名，不接受控制字符。保存/预览/发布时验证当前有效输出，不允许把维度或已移除度量当作样式目标。

阈值最多 8 条，支持 GT/GTE/LT/LTE/EQ/NE，value 为最多 100 字符的十进制数值字符串，color 为六位十六进制。按规则顺序比较原始值，命中第一条即停止；不以百分比/万元显示值比较，null 或非数值不着色。十进制整数运算避免大整数和小数比较精度丢失。未命中恢复默认颜色。

KPI 数字、度量明细、柱图柱体、饼图扇区及折线点支持颜色；折线整段颜色不在本批。Tooltip 使用对应度量格式；共用数值轴继续使用组件格式，不宣称已支持混合单位双轴。查询与联动值不改变。独立格式和阈值参与文档历史、草稿预览、保存和发布冻结，旧样式缺省 metrics=[]。

验收：150 项 BI 测试通过（新增 7 项度量样式/中文别名/规则与输出校验），16 项格式优先级/阈值精度断言通过，原 20 项格式断言通过；13 项 MySQL 检查通过，覆盖双度量、原始值、伪造键/颜色/操作符/数值/超限/重复键、发布冻结。浏览器看板 64 显示 KPI ¥25,567.35元，上海 sales ¥1.335万元为红色，orders 2单为蓝色；把阈值改到 40000 后取消颜色，一次撤销恢复。生产构建通过。原类型检查阻塞未计通过。

保留看板 64「C阶段第七批 · 度量格式与阈值」。其发布版 KPI 高值为绿色，接口测试将草稿高值改为蓝色，体现发布隔离；浏览器改阈值后已撤销，未额外保存。C-02 的组件/度量格式与基础颜色阈值已完成；同比/环比/目标比较、高级条件格式与整段线样式仍待后续。继续 C 素材管理增强和关键体验收口，再进入 D/E。
