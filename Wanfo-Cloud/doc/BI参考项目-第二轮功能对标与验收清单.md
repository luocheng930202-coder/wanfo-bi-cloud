# DataEase 第二轮功能对标与验收清单

日期：2026-10-16。结论：当前系统已有受权限保护的数据源→表数据集→基础图表→看板发布消费链路；仪表板增强、大屏编辑器和模板仍是不同规模的待办，不能以若依菜单、预留表字段或参考项目存在相同入口认定完成。

## 调研范围和证据强度

参考运行入口为 `http://localhost:8100/`，本地参考源码为 `D:/bi-tools/dataease`。沿用 [第一轮报告](BI参考项目-DataEase体验与实施建议.md) 的版本、许可和身份适配边界。本轮不复制实现或静态素材。

- **界面观察**：打开实际配置，记录截图及可访问性树；仅证明该入口、配置与本次结果存在。
- **源码确认**：读取相关调用链；不据此声称运行实例的权限、性能或所有兼容场景已经验证。
- **本项目状态**：按当前代码与前七批验收记录判断。“部分”表示已完成指定子集，“未完成”包括仅有数据库字段、组件占位或历史 POC。
- 本轮不对参考系统进行真实发布、导出、分享、权限变更或原有资源保存验证。未保存的空白大屏中添加了查询组件；在模板生成的未保存画布中试选示例数据集并点击更新数据。没有修改本项目业务代码。
- 注意：参考源码 `DataVisualizationServer.decompression()` 会预写模板扩展记录和静态资源，因此“未保存看板”不等于“零持久化副作用”。本轮不直接清表或删除共享素材；未来自研模板需有暂存归属和过期回收。

## 实际流程记录

### 1. 仪表板高级配置：入口可用，交互效果待验

在茶饮官方示例中选中趋势图，进入“高级→功能设置”。可见缩略轴、空值处理，以及辅助线、条件样式、联动和跳转入口。空值支持保持为空、置为 0、隐藏；这些会影响业务含义，应进入图表配置和验收，不能只当作美化。

![图表高级配置](../../.local/bi-reference/deep/01-dashboard-advanced.png)

未配置真实联动或钻取，没有据此认定其跨数据集映射、空值聚合和跳转权限正确。

### 2. 大屏创建与适配：编辑入口可用，已有大屏未发布

大屏列表的现有资源显示“发布后可查看”，因此没有绕过查看限制。通过空白新建进入编辑器：默认 1920×1080、图层面板、标尺、画布缩放及空格平移；缩放策略包括宽度优先、高度优先、铺满全屏、不缩放、保持比例填充。

组件操作菜单可见上移/下移、置顶/置底、移动到弹窗区域、隐藏、锁定、重命名、复制等。仅观察菜单，未对原有资源执行这些动作。刷新配置区分刷新频率、整体刷新和加载提示；定时行为未运行验收。

![大屏尺寸与适配](../../.local/bi-reference/deep/02-screen-sizing.png)

### 3. 模板选择与预览：可用

从大屏“使用模板新建”进入目录，可按来源、分类和名称筛选。选择“金融数据实时监控大屏”后显示完整预览及应用入口。预览是效果展示，不证明实际组件已连接业务数据。

![模板预览](../../.local/bi-reference/deep/03-template-preview.png)

### 4. 应用模板到编辑器：画布加载成功，业务数据未绑定

应用后打开创建态大屏，图层显示 36 个组件，包含文本、图片、地图、柱图、面积图、明细表、环形图和组合。选中模板图表提示“当前为模板图表，请更换数据集”。没有保存该大屏。

![模板画布](../../.local/bi-reference/deep/04-template-canvas.png)

### 5. 模板替换数据集：入口可用，字段映射未验通

为模板柱图试选已有“茶饮订单明细”。字段区加载了新数据集字段，但原模板的日期、活跃用户、新增用户与示例数据集不匹配。本轮没有看到完整的自动匹配向导，也未建立有效映射或验证正确新结果；点击更新不能作为替换成功的证据。

自研应明确提供旧字段→目标字段映射、类型兼容校验、缺失提示和阻止无效发布，避免依赖静默自动猜测。

![替换数据集后的字段区](../../.local/bi-reference/deep/05-template-dataset.png)

### 6. 数据集和计算字段：预览及编辑入口可用

官方数据集预览显示 60 条示例数据。编辑器包含数据源表列表、自定义 SQL、表关系区域、维度/指标、批量管理、新建计算字段与分组字段。计算字段对话框提供名称、维度/指标、字段类型、表达式、字段引用、函数帮助和校验按钮；打开后取消，未新增字段或保存数据集。

多表关联的连接类型由 `DatasetUnion.vue` 源码确认存在 left/right/inner/full 处理入口，本轮没有拖入新表、验证联接结果或计算表达式求值。

![计算字段](../../.local/bi-reference/deep/06-calculated-field.png)

### 7. 查询组件：绑定模型入口可用，无目标图表时不能完成配置

在空白大屏添加未保存查询组件，进入查询条件设置。界面要求选择关联图表及字段，支持条件必填和查询组件级联配置；空白大屏没有目标图表，因此未完成真实筛选链路。

## 应先固定的技术契约

1. **版本化文档定义**：保留现有 schemaVersion=1 兼容路径，演进为可区分 dashboard/screen 的文档与布局定义。共享组件类型、主题、数据绑定和发布契约；栅格与绝对坐标各自验证，不把所有布局塞入一个未约束对象。
2. **组件注册和能力说明**：图表、指标卡、文本、图片、查询、容器分类型配置，定义默认值、编辑属性、渲染方式和是否取数。不支持的组件明确报错，避免模板导入静默丢失。
3. **消费端与编辑端分离**：编辑元数据需要探索资格；消费仅接受服务器发布的组件/控件 key 和受控值。行列规则、枚举候选、联动、导出均使用当前可信使用者上下文。
4. **样式和素材约束**：样式用有限字段和取值范围；素材有大小/类型/来源限制与归属。首期不接受任意脚本、任意 HTML、任意远程 URL 或模板携带的数据库密码。
5. **模板独立于实际实例**：定义带类型的绑定槽，导入时生成新资源 ID、显式映射字段并重新授权；不携带旧 ACL、连接凭据或实际查询结果。首期只支持本项目格式，不承诺兼容 DET2/DET2APP。
6. **快照与生命周期**：发布复制当时组件、主题和交互绑定；历史回滚不恢复已经撤销的数据权限。模板临时资源、取消创建、异常导入要有清理策略。

## 分批验收顺序

| 批次 | 范围 | 必须满足的验收条件 |
|---|---|---|
| A：定义与编辑体验 | S7-T04/T06，S7-T13（增补） | 旧看板无损读取；主题与标题/卡片/配色可保存重开；发布一致；列表/编辑/查看状态清楚，窄屏保留可用属性入口 |
| B：交互分析 | S7-T05、S6-T32~T36、S8-T19 | 同页两个图表筛选/重置；跨数据集显式类型映射；拒绝伪造字段/操作符/控件；候选值和结果执行使用者行列规则；撤权及时拒绝 |
| C：编辑可靠性与组件 | S7-T14，S6 基础扩展 | 指标卡、文本、图片；复制和删除可撤销，拖拽一轮算一次操作；脏状态和版本冲突明确；组件更改不自动改发布 |
| D：自由画布大屏 | S2-T05、S7-T07/T15、S9-T02 | 设计尺寸、自由坐标、层级/锁定/对齐、等比适配；保存重开及发布消费；隐藏页面停止或降频刷新、无并发堆积、卸载回收 |
| E：本地样式模板 | S12-T01~T06（增补） | 从本项目导出→导入→绑定另一个数据集→校验→保存→按新权限发布；ID 不冲突，不带凭据/ACL/业务结果；失败原子性与临时素材过期清理 |
| 并行业务专项（非多代理） | S5、S4、S9/S10 | 根据实际报表需求补关联与计算字段、Doris 实例验证、导出及性能治理；各自估算，不能用 A 的 UI 验收替代 |

模板协议边界在 A 设计时考虑，模板功能在组件与布局稳定后实现。在线市场、应用模板、跨源联邦、报表/填报、告警、定时报告及 SQL Bot 暂不列入上述首期增强验收。原 MVP 排除在线模板市场的约定保持。

## 后续专项验证及限制

本轮没有完成“真实业务数据集→筛选联动→发布→普通消费者”的参考系统完整业务验收；大屏公开查看受未发布状态限制，模板映射未验通；权限继承、分享、导出、完整键盘路径、读屏和性能均未实测。截图存在窄视口裁切，展示布局问题，不作为桌面像素还原标准。

后续实现前按批次补对应专项即可，不必先把 DataEase 所有模块逐一研究完。优先从 A 开始，并在 B 前制作受控的双图表测试场景。当前不需要重写若依用户/角色系统，也不把 DataEase 的 X-Pack 身份和权限实现迁入本项目。
