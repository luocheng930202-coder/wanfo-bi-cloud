# 基础图表配置、预览与保存（2026-10-16）

本批推进 S6-T01/T02 与基础图表，入口 `/bi-admin/chart`。数据集列表的“建图表”可带入表数据集；看板占位页也增加图表管理入口。

## 已实现流程

选择有权查询的表数据集，配置维度、度量/聚合、嵌套 AND/OR 筛选、排序及最多返回行数，预览图形和明细，保存后可重新打开和编辑。

支持柱状图、折线图、饼图和明细表。图形使用一个维度及 1～5 个数值/计数度量；饼图仅一个度量。表格可用聚合配置，也可点“使用原始字段”生成无维度、NONE 度量的原始记录视图，当前界面最多选择 5 个字段。默认预览 100 行，图表服务端最大 1000 行。非数值度量请使用计数或明细表，饼图负数会提示改用其他类型。

页面可添加/删除筛选条件和分组，输入列表及区间，调整 AND/OR；复用第五批过滤树契约及复杂度边界。修改配置会清除旧结果，异步预览只接受对应配置快照。保存、加载和预览期间禁止修改；离开或打开其他图表前提示未保存内容。

ECharts 采用 Canvas 和 richText 提示，窗口变化时自动调整大小，组件卸载释放实例。原始查询值保留在明细中；超过安全数值范围时提示查看明细。图形数值转换用于展示，不将其作为高精度财务计算输出。

## 图表定义与接口

定义版本为 `schemaVersion: 1`，包含 name、type 与 QueryModel。只保存经过后端校验的配置，不保存查询结果、客户端 SQL 或创建者的权限快照。新增返回 id/version；更新须提交当前 version，数据库条件更新并递增版本。过期版本返回业务 code 409，不覆盖已保存配置。

```json
{
  "version": 0,
  "definition": {
    "schemaVersion": 1,
    "name": "城市数量",
    "type": "bar",
    "query": {
      "datasetId": 123,
      "dimensions": [{"field": "city", "alias": "dimension"}],
      "metrics": [{"field": "id", "agg": "COUNT", "alias": "value_1"}],
      "filters": [],
      "orderBys": [],
      "limit": 100
    }
  }
}
```

datasetId 和字段须替换为实际有权访问的表数据集。定义上限 128K 字符，类型和版本由后端白名单校验；保存前调用与实时查询相同的编译校验。

| 接口 | 功能码 |
|---|---|
| GET `/bi/chart/saved`、GET `/bi/chart/saved/{id}` | `bi:chart:list` |
| POST `/bi/chart/saved` | `bi:chart:add` |
| PUT `/bi/chart/saved/{id}` | `bi:chart:edit` |
| DELETE `/bi/chart/saved/{id}` | `bi:chart:remove` |
| POST `/bi/chart/saved/{id}/data` | `bi:chart:query` |
| GET `/bi/chart/principals`、GET/POST `/bi/chart/saved/{id}/grants`、DELETE 对应授权 | `bi:chart:grant` |

原有 `/bi/chart/data` 用于草稿模型预览，要求数据集 query 功能与资源权限；普通用户依旧不能访问管理员编译调试入口。

## 权限行为

新图表属于当前 BI 用户主体，审计使用可信登录用户名。图表动作支持 view/edit/query/remove/grant，可授予用户、角色和直接部门。若依功能权限、图表资源权限、数据集 view/query 权限分别校验。图表授权不会自动给使用者数据集权限。

列表同时过滤图表查看权限和数据集访问权限。图表定义读取、编辑及取数要求对应数据集查询资格；取数使用服务端保存的模型，不接受请求体覆盖数据集、条件或字段。每次由当前查看者重新解析行列规则，不模拟创建者身份，不缓存结果。当前列权限使已选字段失效时，会拒绝打开/取数，需由有权人员修正定义。

图表功能及资源撤权、数据集撤权、数据规则修改都在后续请求检查。若依角色功能码和成员关系仍受会话快照影响，变更后须重新登录。图表被现有看板引用时不能删除；数据集存在未删除图表引用时不能删除。图表删除采用逻辑删除，旧审计及定义可追溯，本批未提供回收站界面。

此入口面向有数据集探索权的图表使用者。纯看板消费者的授权与代查上下文尚未交付，不能把图表授权当成看板消费策略。

## 部署与架构

升级前备份元数据库。V7 为已有 `bi_chart_view` 增加 definition_json 和 version，为历史图表注册管理员管理资源，不改写 V1～V6，不自动转换旧配置。列表仅展示新版非空定义，旧图表数据保留。

显式重跑 `ruoyi-bi/deploy/ruoyi-menu.sql` 安装图表菜单及功能码。脚本可重复执行，不自动给普通角色授权。若依角色中还需配置数据集列表/查询功能，资源授权在 BI 中配置。当前开发库已升级 V6→V7，菜单已安装。

存储和权限服务继续依赖 BI 内部主体、CapabilityProvider、CurrentActorProvider 及资源授权接口，宿主目录和登录仍留在若依适配器。V7 不访问 sys_*；独立部署包仍按 S11 后续实现。
