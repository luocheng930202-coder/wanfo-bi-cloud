# 全息冰蓝光效：第一批接入

## 使用入口

进入大屏编辑器 → 查看看板属性 → 看板主题与样式 → 选择“全息冰蓝”快捷套装，或在“视觉风格”中选择“全息冰蓝 · 光效”。

“光效强度”范围 0–100，默认 55。0 关闭标题、面板、数字光晕和三维泛光，保留主题配色及全息材质；选择其他风格可恢复普通材质。参数会随草稿、发布、模板文件及“仅使用视觉风格”创建流程保留。

三维场景的旋转和缩放仍可使用；只调光效不重置当前相机。原有“基础”“科技蓝”默认不创建泛光后处理链。

## 已接入效果

- 二维：标题光晕、指标数字光晕、面板内外光晕，以及冰蓝图表配色；自定义非海洋图表配色仍优先生效。
- 三维：现有程序化建筑的半透明材质、建筑边缘线、静态网格/底座光环、冷色主光和 UnrealBloom 泛光；使用 OutputPass 完成颜色输出，避免把后处理线性颜色直接显示。
- 性能：全息场景限制像素比为 1；相机或内容变化才提交绘制，静止时不持续执行泛光渲染。隐藏、退出页面和销毁时保留原有暂停/清理机制；强度为 0 或切换普通主题时释放后处理资源。
- 降级：泛光后处理失败时释放相应资源，恢复默认 framebuffer，并保留基础三维场景与说明；基础 WebGL 本身不可用时沿用静态降级和重试入口。

当前并非 AI 概念图的完整复刻：建筑仍为原型中的程序化模型，光环为静态装饰；尚未加入完整校园 GLB、飞线/扫描动画、镜头漫游和实景反射。也未把整个二维画布转成全屏三维后处理。

## 数据与协议

新增可选外观字段：

```json
{
  "visualPreset": "hologram-ice-v1",
  "glowIntensity": 55
}
```

现有定义版本继续使用 v1；缺失新字段不改变旧看板风格。前后端对新预设和强度进行白名单、整数和范围校验。新预设需配套更新前后端，旧客户端不应自行解释未知风格。

光效只影响展示，不修改查询、度量、权限、地理边界或数据刷新策略；不接收用户自定义着色器和任意 CSS。全息材质当前针对本系统的程序化建筑配置，不代表任意外部模型已经完成适配。
