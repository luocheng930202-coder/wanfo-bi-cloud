# D 阶段第八批：单层容器与父子布局

日期：2026-10-17。状态：单层容器首批闭环完成，D整体及完整容器能力仍部分完成。

## 协议

screen增加container组件，Panel可选parentKey引用同一文档的根容器。成员仍使用画布绝对像素坐标，放入/移出不改位置；容器整体平移统一改变成员坐标，因此相对位置保持。根容器先于成员，成员形成连续图层块；禁止孤立父级、自引用、循环/嵌套、跨类型父级和逻辑组合与容器混用。栅格不支持这些关系。

content.container包含背景（transparent或六位十六进制色）、边框色、整数线宽0～12、圆角0～80和内边距0～40。内边距为画布中从容器外缘计算的设计像素安全范围；成员须完整落入该范围，容器至少保留20×20可用范围。调整内边距/尺寸若挤出成员整次拒绝，不压缩或自动挪动成员。暂无自动布局、嵌套或等比缩放。

旧Panel构造函数和JSON兼容，缺省无父级；原静态内容构造函数兼容，只有container接受容器样式。父子关系和样式参与草稿、版本冲突与发布冻结，消费清单仅返回布局父键及样式，不泄漏查询模型。无数据库迁移，沿用若依功能权限、BI资源和数据策略，未增加宿主身份硬依赖。

## 编辑与状态

组件面板可新增容器。单个未分组、已显示/解锁的组件通过属性选择目标并放入，或移出容器；坐标不变，越出目标范围拒绝。图层列表标记容器内成员，单击成员只选择成员，选中根容器同时选择全部成员；“移动容器”标签提供不被内部卡片遮挡的拖动入口。成员拖动/缩放受父边界限制；有成员的容器通过属性调整尺寸，画布不提供整体比例缩放手柄。

锁定、解锁、隐藏、显示和删除根容器会对整个家族执行；包含已锁成员不能移动或复制，父容器锁定/隐藏不能通过单独操作子级绕过。整容器显示/解锁统一重设成员状态，不是独立状态叠加继承；原个别状态可通过文档撤销恢复。隐藏仍遵守已有规则：涉及筛选目标/联动来源或目标须先解除绑定。隐藏家族不渲染或查询，猜测隐藏成员取数在查询前拒绝。

复制根容器生成新容器键、成员键并重映射parentKey，共同偏移保留内部位置；仍受20组件上限限制。成员单独复制须先移出。置顶/置底以完整容器块为单位；成员调整层次不能破坏块。背景主体不截获成员图表点击，只读仅显示背景和成员，不展示编辑标签。命令走原撤销重做、保存重开与发布机制。
