# D 阶段第三批：标尺、参考线与平移

日期：2026-10-17。状态：编辑辅助基础闭环完成，D 阶段仍部分完成。

## 操作与边界

自由大屏编辑画布新增标尺开关、平移/选择模式、视口复位、参考线吸附开关及水平/垂直参考线添加、拖动、数值修改、单条删除和清空。最多20条参考线，坐标为设计尺寸内整数像素。标尺按当前缩放调整刻度，预留标尺区域，不覆盖画布原点。平移后刻度和参考线跟随设计原点。

平移模式拖动画布仅改变视口，不选择/移动组件；复位恢复平移位置，不修改编辑缩放。参考线吸附默认启用，拖动时按6个屏幕像素换算设计坐标；移动吸附最近的边缘或中心，缩放只吸附右/下边缘，保留组件最小20像素与场景边界。关闭吸附后按原像素拖动。

标尺、平移、参考线和吸附开关仅为本地编辑辅助，不写入看板定义、不产生草稿修改，也不参与文档历史；退出编辑或重开恢复初始辅助状态。组件吸附后的真实位置仍走既有历史、保存、发布冻结。只读预览/消费没有辅助工具、标尺、参考线和缩放手柄。普通栅格看板沿用原画布。

锁定/多选/繁忙时保留既有组件编辑限制；窗口失焦、指针取消、缩放/适配/尺寸变化、路由失活或卸载会结束进行中的手势；卸载时移除窗口监听并释放观察器。无新增若依身份依赖或数据库协议，未来独立宿主边界不变。
