# C 阶段第三批：设计器内组件图表字段配置

日期：2026-10-17。本批完成在当前看板组件内配置字段，不把共享源图表当作组件草稿覆盖。

## 操作

选中图表或指标卡，在「组件属性 → 数据绑定 → 配置图表字段」打开编辑框。支持柱状图、折线图、饼图、明细表，维度、多个度量及聚合、度量别名、多项排序、返回行数与嵌套附加筛选。指标卡取第一个聚合度量，自动去维度与排序。图形校验沿用现有约束；切换饼图不会静默删除多余度量，需要明确移除后应用。

修改在对话框内暂存；「验证并应用」执行当前编辑者权限下的服务端查询，成功后才作为一条文档历史命令写入组件并刷新结果。失败保留输入和错误；取消不改变文档。恢复源图表配置同样先验证，且可撤销。锁定组件不可编辑。更换绑定源图表清除旧组件配置，避免字段配置跨数据集串用。复制组件保留其配置副本。

编辑画布刷新、撤销重做后的重新取数和草稿交互预览统一走看板作者预览协议。单卡刷新使用只含该组件、无交互的临时定义；不会保存或应用其他组件的默认筛选。整板交互预览仍执行其控件与联动配置。

## 协议与权限

Panel 新增可选 chartConfig：`{type,dimensions,metrics,orderBys,limit,filterTree?}`。旧文档缺省时沿用源图表；不需要数据库迁移。该对象不提供 datasetId、SQL、源 filters 或源 filterTree 的替换入口。type 与字段白名单、聚合、输出别名、排序、嵌套筛选深度等继续交由统一图表验证器及查询编译器校验，limit 为 1～1000。

服务端每次保存、预览、发布都先按 chartId 导出有权读取的源图表，复制查询后覆盖允许的显示/查询槽位。源数据集始终固定，源 legacy filters 原样保留，源 filterTree 与组件 filterTree 用 AND 组合；再次叠加看板运行筛选与当前身份的行列规则。恢复组件筛选不移除源图表固定条件。源图表后续发生字段或结构变化时重新校验，失效配置必须修正。

草稿存组件配置，发布快照存已解析的有效查询，因此修改草稿不改变已发布查询。查看端清单仍不暴露 chartId/chartConfig/QueryModel。功能资格沿用若依 CapabilityProvider，BI 资源授权和 CurrentActorProvider 保持宿主隔离，不增加宿主用户字段。query 与 consume 的既有隔离保持不变。

联动第一维度按组件有效维度识别；已有联动不自动改写。来源字段失效时后端拒绝保存/预览，交互编辑器提供「更新为当前第一维度」入口，用户明确修正绑定。
