# C 阶段第八批：素材检索、重命名与授权

2026-10-17。C7 完成后继续实施 C 素材管理增强，没有重做用户身份或复制若依用户表。

## 功能与协议

素材库新增按名称搜索、重命名与授权按钮。名称搜索大小写不敏感，最长 200 字符，按字面匹配；资源权限过滤先于搜索计数与分页，未授权用户不能由搜索 total 推断私有素材。列表返回 resourceActions，按钮同时依赖功能资格与资源动作；后端独立执行相同检查。

新增 bi:asset:edit / bi:asset:grant 功能码，已补幂等若依菜单安装脚本。重命名 PUT /bi/asset/{id} 接收 `{name,expectedName}`，服务端按旧名称精确比较后更新，冲突返回 409；不替换图片内容。元数据库现有字段足够，本批无新增迁移。大小写不同的旧名称也不能绕过比较。

授权支持 BI 主体目录中的用户、角色和直接部门，动作 view/edit/remove/grant。主体搜索 GET /bi/asset/principals，授权列表及新增 GET/POST /bi/asset/{id}/grants，撤销 DELETE /bi/asset/{id}/grants/{principal}/{action}。管理授权需功能资格与素材 view+grant，不能对已删除素材继续授权。查看不包含编辑、删除或转授权；编辑/删除/授权也不替代所需的功能码。

素材选入前重新 GET 详情，权限撤销或资源删除时清除候选并提示重选。撤权阻止新读取和新选入，不追回此前有权读取且已保存到看板的图片副本。复制语义与首批一致。
