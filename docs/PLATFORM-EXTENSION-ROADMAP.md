# 平台扩展实施清单

本文按平台扩展优先顺序追踪实现与未覆盖边界。

## 1. API 数据源增强

- [x] GET / POST JSON 请求参数与页码分页
- [x] 定时同步
- [x] OAuth 2.0 客户端凭据取令牌；凭据加密保存，每次同步刷新
- [x] 可选展开嵌套对象为点号列名
- [ ] OAuth 授权码/刷新令牌、游标分页、嵌套数组展开

请求与令牌地址仍受服务端同源白名单约束；最多 5 MB、20000 行、30 秒。嵌套数组需上游预整形。

## 2. 文件数据源增强

- [x] CSV / Excel 预览和手动字段类型
- [x] 追加或覆盖
- [x] 按行拒绝或跳过并返回异常行号、字段和原因
- [x] 明确选择时可覆盖并替换字段结构
- [x] 交互式字段映射（重命名、映射旧字段、忽略字段）、全行/业务键去重
- [x] 结构替换前预览新增/移除字段并二次确认
- [ ] 自动字段建议、依赖数据集字段自动迁移和回滚

追加可映射重命名字段，缺少的目标列补空值；业务键去重保留最后出现的数据行。结构替换仍可能让依赖数据集字段失效，现仅做风险预览和确认，用户需重新同步字段。

## 3. 数据加工能力

- [x] 已有字段公式、单表关联、UNION 数据集能力
- [x] 计算字段可依序引用之前的计算字段，支持有限安全公式函数
- [x] 样本质量报告：空值、不同值、重复值、重复行
- [ ] 多个关联表的图形化关系模型、清洗步骤的编排/回放、全量精确质量扫描和规则阈值管理

质量报告最多统计当前用户可见的 100 行样本，不能证明全表无质量问题。

## 4. 新图表类型

- [x] 热力图、矩形树图、旭日图、桑基图、箱线图、直方图、瀑布图、经纬度散点地图
- [ ] 更丰富的层级路径、地图底图/坐标投影、分箱与异常值自定义样式

箱线图按最小值/Q1/中位数/Q3/最大值展示；直方图采用最多 20 个、约平方根样本数的等宽分箱；经纬度地图为经纬度坐标散点。

## 5. 分析算法

- [x] 线性回归趋势线、3 点移动平均、线性外推最多 12 个等间距周期
- [x] 均值 ± k 倍总体标准差异常点标记（k 在 1～4）
- [ ] 时间序列季节性预测、置信区间、稳健异常算法和业务指标验证

当前算法仅使用图表已查询聚合序列，不包含季节性或置信区间；分类索引按等间距处理。

## 6. 报表订阅

- [x] 定时生成已保存图表/已发布看板，支持 CSV / Excel / PDF 邮件附件
- [x] 订阅管理、暂停/启用、删除、执行历史与最近状态
- [x] 每次执行重新解析订阅人的当前身份并校验资源和数据权限
- [x] 失败后延迟重试，连续 3 次失败自动暂停；审计记录不保存邮件地址或数据内容
- [ ] 邮件投递外的通道（站内/企业微信）、自定义日历与时区、通知模板和管理员全局审计

当前使用 SMTP。部署时需设置 `bi.report-subscription.enabled=true`、`bi.report-subscription.allowed-domains` 域名白名单和 Spring Boot `spring.mail.*`；默认关闭，不配置邮件服务/白名单时不能新建或启用订阅。附件最大 8 MB，单次最多 10 个收件人。首次运行按设定间隔后执行，支持 15 分钟至 7 天周期。仓库不含 SMTP 凭据，也未执行真实邮件投递验收。
