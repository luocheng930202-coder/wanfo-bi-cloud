# D 阶段第七批：边框与分割线

日期：2026-10-17；状态：装饰组件基础闭环完成，D阶段仍部分完成。

## 协议与操作

大屏增加border与line组件，content.decoration保存固定样式：六位十六进制颜色、整数线宽1～12、solid/dashed/dotted线型、整数圆角0～80、horizontal/vertical方向。边框用圆角，分割线按组件宽/高绘制横/竖线；不自动交换组件尺寸。旧Content(text,image)构造函数和JSON兼容。

仅screen允许装饰组件；不能混用文本/图片/数据载荷，禁止任意CSS、HTML、脚本和外部资源。组件按既有20个上限、像素边界、分组、锁定、隐藏、复制与层序处理，样式参与文档历史及保存/发布冻结；无数据库迁移或宿主身份依赖。

组件面板有边框/分割线入口，属性编辑颜色/线宽/线型/圆角/方向。编辑端显示名称与拖动入口，消费端不显示卡片标题和刷新按钮，仅显示图形。透明装饰层不截获图表点击；编辑标题及缩放手柄仍可操作，主体也可通过图层面板选中。新类型无数据请求，装饰不改变原查询或筛选联动。
