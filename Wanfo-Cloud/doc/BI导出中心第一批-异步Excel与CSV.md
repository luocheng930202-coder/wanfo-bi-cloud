# 导出中心第一批：异步任务 + Excel/CSV

日期：2026-10-18。状态：S9-T06/T07/T08 内部 MVP 首批完成。不包含 PDF、流式百万行、对象存储、失败重跑旧任务、分享/嵌入。

## 使用方式

已保存图表工具栏可提交 CSV / Excel。已发布看板查看页「导出数据」可导出全部数据组件（Excel）或指定一个组件（CSV/Excel），并带上当前已应用的筛选和联动。任务出现在「导出中心」，排队执行后由提交人下载，文件保留 7 天。

## 边界

- 只接受 `sourceType=chart|dashboard` 与已保存/已发布 ID；拒绝 QueryModel、SQL、数据集 ID、密码等查询条件。
- 提交、异步执行、下载都使用当前用户身份；工作线程通过 ActorScope 绑定提交时的主体和功能权限快照，并再次走图表 query / 看板 consume 与行列规则。
- CSV 使用 UTF-8 BOM；单元格以 `=` `+` `-` `@` 及全角形式开头时加 `'`，避免公式注入。Excel 为最小 OOXML，不引入 EasyExcel。
- 行数沿用图表/组件上限（编译器最多 10000），文件不超过 8MB；同时最多 3 个排队或执行中的任务。服务重启会把未完成任务标为失败。
- V2 `bi_export_task` 仍闲置。本期使用 `bi_export_job` 存文件字节，不写查询定义。
