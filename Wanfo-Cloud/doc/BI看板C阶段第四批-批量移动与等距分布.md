# C 阶段第四批：批量移动与等距分布

日期：2026-10-17。本批完善栅格编辑效率，不改变后端协议、权限或发布消费逻辑。

## 操作与边界

选中多个组件，在组件属性中使用「批量移动」与「等距分布」。移动步长为 1～12 个整数栅格，提供上、下、左、右按钮；多选时方向键移动 1 格，Shift + 方向键移动 5 格。输入框、可编辑文本、对话框和预览模式保留原有按键行为。移动只改变所选组件 x/y，保持尺寸、相对位置、字段配置和交互绑定，不通过 GridStack 推挤其他组件。

等距分布至少选择 3 个组件，按所选组件在目标轴上的坐标排序，与点击选择顺序无关。整体最小起点与最大终点保持不变，按组件实际尺寸分配剩余空隙。通过累计距离四舍五入落在整数栅格，相邻间距最多相差 1 格；不宣称亚栅格精确相等。另一轴坐标及未选组件不变。投影空间不足则拒绝，先调整两端外边缘。

含任意锁定项、所选组件已失效、结果越界或与任何组件碰撞，整条操作拒绝并保留原布局。移动与分布通过完整文档校验后一次替换 panels，构成一条历史命令；一次撤销恢复整组，重做恢复操作。无变化不新增历史。位置限制仍为 12 列、120 行及组件尺寸范围。多选仍禁止单卡拖动缩放，群组鼠标拖动不在本批范围。
