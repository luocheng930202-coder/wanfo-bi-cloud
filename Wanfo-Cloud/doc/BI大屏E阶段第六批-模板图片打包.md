# E 阶段第六批：模板图片打包

日期：2026-10-18。状态：看板/大屏 v1 布局文件可内嵌已校验 PNG/JPEG/WebP，S12-T03 图片子集完成；S12-T06 首批暂存/回收见 [BI素材S12-T06第一批-暂存与回收](BI素材S12-T06第一批-暂存与回收.md)。

## 使用方式

设计器「导出模板」把当前图片组件打进 `.bi-screen.json` / `.bi-dashboard.json`，或保存到同一私有模板库。导入与实例化按原样复制图片内容，不走素材库 ACL，也不改写为远程地址。模板预览直接显示打包图。空图、远程 URL、SVG 与伪造魔数会拒绝导出和入库。

## 边界

- 仅 `data:image/(png|jpeg|webp);base64,...`，真实文件头，单张解码后 ≤256KB，每文件最多 5 张；模板上限由 512KB 调整为 2MB。
- 仍拒绝 chartId/datasetId/password/jdbcUrl、查询结果、旧 ACL 与 DataEase 文件。
- 不包含素材暂存归属、对象存储、取消/失败/过期回收、引用式保护或跨版本迁移。
