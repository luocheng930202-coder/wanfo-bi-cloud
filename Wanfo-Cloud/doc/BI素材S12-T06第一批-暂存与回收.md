# S12-T06 第一批：素材暂存与过期回收

日期：2026-10-18。状态：设计器/素材选择器支持服务端暂存；持久素材库行为不变。

## 已实现

- Flyway `V12__bi_image_staging.sql`：`bi_image_staging` 表，按 `owner_principal` 隔离，默认 24 小时 `expire_time`。
- 接口（需登录，功能权限见下）：
  - `POST /bi/asset/staging` 上传暂存（校验规则与看板图片一致，含 WebP）。
  - `GET /bi/asset/staging/{id}` 读取本人未过期暂存。
  - `POST /bi/asset/staging/release` 批量释放（取消/离开设计器）。
  - `POST /bi/asset/staging/{id}/promote` 转入素材库（`bi:asset:add`）。
- 每用户最多 30 条未过期暂存；列表/过期清理在写入与 `@PostConstruct` 时执行 `purge`。
- 前端：看板设计器本地上传优先走暂存；素材库对话框增加「暂存上传」；关闭未使用暂存会 `release`；保存草稿成功后释放会话暂存（图片副本已写入看板 JSON）。
- `BiPermission.anyOf`：暂存接口允许 `bi:asset:add` / `bi:dashboard:edit` / `bi:dashboard:add` 任一。

## 第二批（同批交付）

- Flyway `V13__bi_chart_template_lease.sql`：数据集直绑生成的图表可登记租约（7 天）。
- `POST /bi/chart/template-lease/release` / `commit`：模板向导取消/返回释放孤儿图表；创建看板成功后 commit。
- 保存图表 `templateLease: true` 时自动登记租约；`BiMaintenanceConfiguration` 每小时清理过期暂存图与租约图表。

## 未包含

对象存储、引用式保护、跨主体暂存共享、百万行分页取数导出。

## 验收建议

1. 设计器上传图片 → 表中有 staging 行 → 保存看板后 `release` 成功且草稿内图片可预览。
2. 素材库「暂存上传」后关闭对话框不点使用 → staging 行删除。
3. `promote` 后出现在素材库列表且 staging 行删除。
4. 普通「上传到素材库」仍立即持久化，不自动过期。
