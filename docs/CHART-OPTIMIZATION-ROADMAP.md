## 2. 独立图表工作区

当前路由：`/bi-admin/chart-workspace/:id/view`、`/bi-admin/chart-workspace/:id/edit`；新建使用 `/bi-admin/chart-workspace/new`，均显示在数据中心主内容区。旧 `/bi-chart` 和 `/bi-designer` 地址保留重定向。

打开预览：只读配置、自动查询、图表优先展示，可查看数据和刷新。编辑：字段区、中央预览区、右侧属性区；进入后自动显示保存版本的数据。两个模式分别检查查询、查看、编辑权限，不能仅凭 URL 决定权限。

进入流程：读取定义 → 兼容旧版本配置 → 读取字段/参数 → 校验权限和必填参数 → 自动查询 → 渲染。已有保存图表通过保存图表查询接口取数，保留资源授权及数据权限；不得为自动查询绕过授权改用数据集接口。

行为要求：

- 默认通过同页子路由打开工作区，不创建浏览器窗口，不在列表下方追加编辑器。
- 有默认参数时自动运行；缺少必填参数时定位到参数输入区，填写后运行。
- 显示加载、空结果、无权限、字段失效、查询超时及重试状态；错误不展示真实连接凭据或原始敏感 SQL。
- 进入只触发一次初始查询；快速切换资源或参数时取消旧请求，旧响应不得覆盖新图表。
- 数据配置变化按自动查询开关执行，开启时防抖；纯样式调整只重新渲染，不重复请求数据库。
- 刷新页面可恢复已保存图表；离开未保存编辑时提示。保存完成更新真实缩略图，并让列表按资源 ID 和版本刷新。
- 查询结果显示更新时间、耗时及截断提示；预览、编辑、看板和大屏使用相同配置解释与渲染规则。

验收：两张不同图表分别打开后自动显示各自数据；原列表位置不变；有权限和无权限账户分别验证；失败可重试；刷新及直接访问路由有效；编辑保存后卡片缩略图与新版本一致。

## 3. 配置面板的职责

| 面板 | 应包含内容 | 不应混入的内容 |
| --- | --- | --- |
| 数据 | 数据集、字段角色、类型校验、聚合、时间粒度、过滤、排序、Top N、查询参数 | 字体、柱宽、圆角 |
| 样式 | 主题、色板、字体、标题、图例、提示框、轴、标签、图形、数字格式 | 改变统计口径的计算 |
| 高级 | 钻取、联动、参考线、条件规则、同比环比、异常标识、刷新、缩放、性能策略 | 不适用的其他图表选项 |

高级分析不是所有图表通用。同环比需要时间字段、比较周期与缺失期策略；钻取需要维度层级；预测或趋势拟合需额外算法支持，先作为规划能力，不直接承诺现有支持。

## 4. 通用数据约定

- 字段需有稳定 ID、来源字段、别名、数据类型及展示名称，不能只靠中文标签关联配置。
- 分类维度、时间维度、数值指标、系列分组、提示信息、地区编码、经纬度、父子关系是不同角色。
- 数值指标支持适用的 SUM、AVG、MIN、MAX、COUNT、COUNT DISTINCT；文本和日期通常只允许计数/去重计数。已有聚合表达式避免重复聚合。
- 明细表支持原始列，不默认聚合；展示用的千分位、百分号、单位转换不能改变查询原值。
- 时间字段声明日/周/月/季/年粒度、时区、周起始日、补齐规则；时间趋势按真实时间顺序排列。
- 空值、零值、非法数值、负值分别定义处理规则。除零显示为无效或空值，不显示无穷大。
- Top N、其他项、排序、过滤与聚合的先后顺序必须明确；百分比说明分母是全量还是筛选后结果。
- 多指标不同单位时必须分别设置数值格式；同轴可比性不足时提示，双轴图明确左右轴归属。
- 前后端共同校验字段数量、角色及能力；拖入不兼容字段时说明原因，提供可执行的修正建议。

## 6. 视觉优化标准

1. 建立商务浅色、分析简洁、深色大屏三套基础主题，先保证默认效果；分别调整背景、文本、网格和图例对比度，避免只换色板。
2. 提供分类色板、连续色板、正负发散色板；同一系列跨图表保持同色，业务阈值单独使用语义色，不用颜色作为唯一编码。
3. 按图表类型提供预设，例如清爽分组柱、排名条形、细线趋势、柔和面积、中心指标环、轻量明细表；预设包含布局、文字、图形和提示框。
4. 控制视觉噪声：网格适度、标签不重叠、小值标签按阈值隐藏但保留提示；避免默认 3D 和不必要装饰。
5. 响应式规则覆盖窄卡片、独立编辑区和大屏：按空间调整图例位置、标签密度、内边距，不简单按比例缩小所有文字。
6. 数字格式按指标定义：金额、数量、比例、小数、千分位、万/亿、负数、空值；提示框与轴标签可不同精度，但语义保持一致。
7. 样式修改即时预览，支持恢复默认、撤销和预设切换；应用主题时保留明确的用户覆盖项，并提供清晰反馈。

## 7. 按图表类型动态生成配置

建议建立图表能力注册表，每个类型声明：

- `dataRoles`：角色名称、字段类型、必填性、最少/最多数量、聚合和角色冲突规则。
- `styleSections`：适用样式分组、控件类型、默认值、范围、可见条件。
- `advancedSections`：支持的分析/交互能力及启用前提。
- `presets`：该类型专用的主题预设。
- `validate`、`migrate`：配置校验与旧版本升级规则。
- `queryAdapter`、`renderer`：数据语义转换和渲染实现；查询及权限仍由后端控制。

示例：环形图显示内半径和中心文字，不显示 X/Y 轴；透视表显示行列维度和总计，不显示柱宽；组合图显示每系列图形及轴绑定；散点图显示 X/Y 数值角色，而不是笼统的“度量 1/度量 2”。

配置分类必须影响真实运行结果：保存、重新打开、独立预览、看板、大屏和缩略图一致解释。未实现的选项不作为可用控件展示。

切换图表类型：保留兼容字段和样式；不兼容项列出原因，由用户确认映射或移除，不静默丢失。旧版定义有 schemaVersion 迁移，缺省值稳定。服务端拒绝无效字段组合和越权查询，不信任前端校验。
