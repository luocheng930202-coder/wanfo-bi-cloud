# BI 质量收口第一批验收（2026-10-19）

本批完成约定的五项工作，沿用若依权限及宿主中立身份契约。未扩展 SaaS、多租户或指标模块；保留工作区既有变更。

## 1. 计算字段类型与旧数据修复

计算公式先经 AST 白名单解析，再由 Calcite 在物理字段元数据上验证并推断真实类型，不执行业务查询。保存数值、字符串、日期等推断结果，继续执行聚合类型检查，字符串不能通过 SUM 校验。推断与查询同时启用 standard/mysql 函数，覆盖 CONCAT。关闭宽松隐式类型转换，错误参数在保存时拒绝。

启动修复器扫描旧 CALC 字段，按原公式和当前字段元数据推断，并使用公式与旧类型条件更新，支持重复启动。无法推断的旧公式记录字段 ID 并保留受限状态，不能随意改为数值。类型推断不新增计算字段之间的递归依赖能力，也不表示所有数据库方言均已验收。

## 2. 模板协议与远程读取

服务端校验 v1 大屏和仪表板模板的格式、字段白名单、组件类型、尺寸边界、栅格重叠、父子关系、组合及图片；拒绝业务数据绑定、未知属性和原型污染键。设置递归深度、节点数及组件数上限。文字内容出现 password/chartId 等词汇不会被误判为结构属性。

远程目录和布局均按上限读取流，不依赖 Content-Length；超限拒绝，禁止自动重定向。目录自身源默认可信，额外源需通过 `bi.template-market.allowed-origins` 显式配置（协议、主机、端口构成 origin）。不接受 URL 内嵌凭据；classpath 限定模板目录。请求超时限制为 3～60 秒。远程目录异常回退内置模板；受信源内的布局仍须通过协议校验。

修复一份内置栅格模板携带前端不接受的 hidden 属性，并增加“全部内置模板经过真实前端解析器”回归。

## 3. 分享安全与访问记录

新密码使用带盐的 BCrypt（cost 12），输入先做 SHA-256，存储带 `{bcrypt-sha256}` 标识，避免长密码受 BCrypt 字节截断影响；旧 SHA-256 密码成功校验后通过条件更新升级。密码不进入访问日志。

失败预算存储于 MySQL，以链接和当前登录访问者为维度：10 分钟内 5 次错误后暂时拒绝；成功校验清除计数，过期重新计数。正常组件并发读取不消耗错误预算；已经进入验证的并发请求可能先于阈值提交，不宣称严格限制所有在途校验。

viewer 与 publisher 模式均重查当前身份资格，禁用用户拒绝访问；publisher 同时校验当前发布者资格。分享仍要求登录。查看、组件取数、选项读取、密码错误、限次和权限拒绝写入审计。发布者可在分享弹窗查看最近 200 条访问记录，不返回密码散列或链接 token。

维护任务默认每 10 分钟运行，清理一天前的尝试窗口及过期审计；`bi.share.audit-retention-days` 默认 90，允许 1～3650 天，每批最多删除 1000 条。当前未增加审计导出或独立审计管理中心。

## 4. 填报人工核对

核对端点实时校验管理员、填报功能与目标数据集查看/查询/写入权限，核实记录属于该表单。要求提供 5～500 字核对依据。

- pending：仅允许补充依据，不能确认终态，以免与仍在执行的任务冲突。
- uncertain：可补充依据，或在检查源库业务唯一标识、事务结果后确认已写入/未写入。
- 状态更新匹配预期状态，过时操作返回冲突；状态和追加核对审计在同一事务内完成，审计失败回滚状态。

记录页展示状态、核对说明、处理入口与历史。修复显式 SELECT 漏查新增核对列的问题，新增 Mapper 回归断言。核对只维护提交记录，不执行源库 DML，也不自动重试。跨库没有 XA；中断后遗留 pending 的执行恢复另行处理，本批不宣称分布式原子提交或自动补偿。
