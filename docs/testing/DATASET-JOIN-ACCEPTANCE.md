**“两张物理表关联后，再在画布中关联已保存的第三个 SQL 数据集”目前不能直接配置，不能判定为通过。**

## 等价 SQL 与已核对结果

```sql
SELECT s.school_id,s.school_name,s.district,
       o.order_id,o.amount,b.budget_total
FROM qa_ds_20261105_school s
LEFT JOIN qa_ds_20261105_order o ON s.school_id=o.school_id
LEFT JOIN (
  SELECT school_id,SUM(budget_amount) AS budget_total
  FROM qa_ds_20261105_budget GROUP BY school_id
) b ON s.school_id=b.school_id
ORDER BY s.school_id,o.order_id
```

数据库等价查询返回4行、金额550，已通过只读自动核对。另已验证先把订单汇总到学校，再关联预算，得到3行、采购总额550、预算总额650。

**口径提示：**预算属于学校粒度，明细查询中 School A 的250会重复显示；直接对4行预算求和会得到900。计算总预算应在学校粒度聚合，不应使用 SUM(DISTINCT budget_total) 修补，因为不同学校可能拥有相同预算。
