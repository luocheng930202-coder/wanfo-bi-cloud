# D 阶段第四批：组合、图层与全屏展示

日期：2026-10-17；状态：D4组合与图层基础闭环、D5全屏展示入口完成，D阶段整体仍部分完成。

## 组合协议与交互

大屏Panel新增可选groupKey，1～64位字母/数字/下划线/短横线；同组至少两个组件。旧构造函数/旧JSON默认无组合。栅格看板不接收组合；本批为单层逻辑组，不是嵌套容器树，不增加组件数量。位置仍为场景内绝对像素，组不改变原数据查询、筛选及联动绑定。

点击成员扩展为全组选中，支持解组、整体拖动/方向键移动、整组锁定/解锁、复制、删除、置顶和置底。拖动以组合包围框限制场景边界并吸附参考线，成员相对位置保持，鼠标抬起提交一次布局。组内任一成员锁定时整体编辑受阻。组合内单独改尺寸/对齐/分布须先解组，暂不做组合等比缩放和嵌套。

复制为全部成员分配新组件键、为各个组分配新groupKey，并以共同偏移保持相对位置，保留20组件上限。成员移除入口扩展为整组删除，原筛选/联动清理及确认逻辑复用，撤销恢复整组。置顶/置底扩展组选择，保留成员内部和其他组件相对层序。命令参与原文档历史，选择任意成员仍能在重开后选中整组。

前后端校验组合并随草稿、发布快照保存；消费仅按冻结坐标和图层渲染，不提供编辑选择或组合控制。单组件编辑取数预览去掉编辑分组标识，避免孤立成员触发完整文档约束。沿用若依功能权限、BI资源和数据策略，未引入宿主身份硬依赖或新增数据库迁移。

## 全屏展示

草稿交互预览与发布查看共用全屏入口，只对现有大屏画布请求浏览器全屏，不复制/重挂载查询页面。可点退出或按Esc返回；全屏变化驱动画布原有尺寸观察器重新适配，留白沿用大屏背景。全屏切换保留筛选、联动及已加载数据，不直接发起查询；自动刷新仍按原设置运行。

全屏仅包含画布，修改外部筛选控件先退出全屏。浏览器拒绝/不支持时显示提示；路由失活或卸载退出自己拥有的全屏，卸载移除fullscreenchange及键盘监听。未改变其他组件拥有的全屏状态。该入口只用于大屏，普通栅格看板不改变。
