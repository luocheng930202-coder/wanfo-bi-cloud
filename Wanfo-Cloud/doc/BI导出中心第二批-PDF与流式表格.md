# 导出中心第二批：PDF 与流式表格编码

日期：2026-10-18。状态：在第一批异步任务模型上扩展格式与编码实现。

## 已实现

- **PDF**：单表导出（已保存图表或看板单个数据组件），横向 A4 表格，标题 + 表头；中文优先 `STSong-Light`，不可用时回退 Helvetica。
- **流式 CSV**：按行写入 `OutputStream`，CSV 行上限提升至 **100,000**（仍受查询结果与 8MB 文件上限约束）。
- **流式 Excel**：`SXSSFWorkbook`（窗口 200 行）替代全内存 OOXML 拼装，xlsx 行上限仍为 **10,000**。
- 前端：图表页、看板消费页、导出任务提交支持 `pdf` 格式。

## 未包含

分页拉取百万行、图表可视化截图、PDF 水印、对象存储、失败任务重跑 UI。

## 验收建议

1. 图表导出 PDF → 导出中心下载，文件头 `%PDF`，表头与 CSV 一致。
2. 多看板组件仅选其一可提交 PDF/CSV；全板仍为 Excel。
3. 大结果集 CSV 任务在 8MB 内成功或给出「文件过大」提示。
