# D 阶段第六批：图层隐藏与取数边界

日期：2026-10-17；状态：基础闭环完成，D整体仍部分完成。

## 协议与操作

screen Panel新增可选hidden布尔值，旧文档缺省false；栅格不能设置true。同一groupKey成员必须整体隐藏或显示。设计器提供隐藏/显示所选，图层列表标记隐藏，可选择隐藏成员恢复；支持既有锁定约束、整组语义、撤销重做、保存及重开。隐藏仍占20组件数量与图层顺序位置；不改位置、内容、查询配置和素材副本。

隐藏后不渲染编辑画布、不做编辑器自动/单组件刷新；未结束的旧响应通过请求代次和可见性检查丢弃。隐藏组件的字段和引用仍须通过作者权限校验，隐藏不是授权机制。全部隐藏时显示恢复指引；允许保存这样的草稿，但拒绝发布无可见组件的大屏。

若组件参与控件目标、联动来源或联动目标，隐藏前须显式解除相应绑定；前后端均拒绝直接隐藏，不自动删除交互配置。交互编辑器不提供隐藏组件作为新绑定候选。这样不会用隐藏图表继续为联动或枚举候选取数。

## 预览和消费

hidden随草稿及发布快照冻结。草稿整板预览不返回隐藏组件的载荷和展示清单；发布清单不返回其布局、内容和样式。消费者猜测隐藏组件key请求数据返回403，在执行查询前拒绝。显示草稿不改变已发布隐藏状态，须重新发布才生效。

引用和资源权限继续校验，隐藏不释放依赖、不替代数据集消费/行列权限，不引入若依身份硬依赖；无数据库迁移。普通栅格、原静态素材副本和版本并发策略保留。
