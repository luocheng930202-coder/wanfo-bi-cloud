## 1. 使用约定

- 按依赖和阶段门推进。每项任务以代码、迁移、权限、界面/接口验收和说明齐全为完成条件。
- 标记 **已有基础** 只代表可复用；**代码待验证** 代表工作区已有实现但尚未构建/验收；**迁移草案** 代表 SQL 文件已写但未执行；**待开发** 代表尚未形成可验收实现。
- 任何 schema 变更只新增 Flyway migration；已应用迁移不可编辑。生产结构应先做只读 DDL 差异检查。
- 现有 `bi_*` 表继续拥有 BI 资源事实；`dp_*` 只保存平台治理数据、索引和历史快照，不复制凭据、业务行或 BI 定义。
