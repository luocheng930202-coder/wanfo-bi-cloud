# E 阶段第四批：私有布局模板库

日期：2026-10-18。状态：大屏布局可保存到本项目模板库并按 BI 资源授权列出/使用，S12-T02 仍部分完成。

## 使用方式

设计器「导出模板」可下载文件，或填写名称/分类后「保存到模板库」。库内模板不含数据绑定、凭据、图片。新建数据大屏时，有权查看或使用的私有模板与内置布局一起出现；使用流程仍是重新绑定数据集/图表后创建独立草稿。

## 边界

- 新增 `bi_screen_template`（Flyway V10）与资源类型 `template`（view/edit/remove/grant/use）。
- 功能码 `bi:template:list/add/edit/remove/grant`；超级管理员 `*:*:*` 可直接使用。普通角色需执行 `deploy/ruoyi-menu.sql` 后授权。
- 不包含模板市场、仪表板模板、图片打包、素材暂存回收。
