# 管理卡片的真实预览

`BiResourceThumbnail` 复用生产用 `ChartPreview`、`DashboardCanvas`、`DashboardCard`，根据资源 ID 和保存版本动态生成缩小后的真实视图。不是随机封面，也不把某位用户的业务数据保存为公共 PNG。

- 图表保存、看板保存、自由大屏保存统一触发 `bi:saved-resource`；只有保存成功才触发，版本冲突不触发。图表保存也使当前列表中的看板预览重新读取图表配置。
- 列表返回、手动刷新、版本变化时重新生成；旧记录首次进入可视区域也会生成，无需重新保存历史记录。最多同时生成两张卡片，翻页和离开页面后丢弃过期结果。
- 编辑者看已保存草稿；使用者看不可变发布版本。缩略图标明实际预览版本。草稿与发布版本采用现有的独立权限接口。
- 业务数据通过当前登录用户的原有接口查询，继续执行图表/数据集权限及行列规则。不建立跨用户图片或数据缓存。无权限、无数据、请求失败分别显示实际状态，失败可重试。
- 图表定义和取数是两个旧接口，查询前后复核版本，避免保存期间混用旧样式和新数据；看板草稿、发布取数沿用后端版本校验。
- 图表预览隐藏编辑操作和附加明细；表格、透视表保留本身的表格视图。看板保留栅格位置，自由大屏保留场景尺寸、顺序、隐藏状态、容器、图片、文字、主题和组件配置，完整等比缩小。

这是动态渲染方案，打开列表需要有权限的预览/取数接口可用；不是后台截图任务或持久化静态图片服务。已有版本定义就是持久化来源，因此本次无需数据库迁移。

验证：`node --test scripts/bi-thumbnail*.test.mjs scripts/bi-panel-queue.test.mjs`，`npm run typecheck:bi`，以及管理页面的浏览器视觉验收。
